# Kitchain frontend

Angular standalone application. See [the root README](../README.md) for setup and [architecture](../docs/architecture.md) for scope and decisions.

- `npm ci` — install locked dependencies
- `npm start` — development server at http://localhost:4200
- `npm run lint` — TypeScript and Angular template linting
- `npm test -- --watch=false` — Vitest foundation tests
- `npm run build` — production build
- `npm run format:check` — Prettier validation

Routes: `/`, `/courts`, `/play`, `/gear`. All product pages are honest placeholders.
